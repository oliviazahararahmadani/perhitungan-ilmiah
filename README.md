
# Kalkulator Ilmiah (Scientific Calculator)

## Deskripsi Program
Kalkulator Ilmiah adalah aplikasi berbasis web yang digunakan untuk melakukan perhitungan matematika dasar dan ilmiah. Program ini dibuat menggunakan tiga teknologi utama, yaitu HTML, CSS, dan JavaScript.

Aplikasi ini memiliki tampilan sederhana, menarik, dan mudah digunakan untuk membantu pengguna melakukan perhitungan matematika melalui browser.

## Tujuan
1. Menerapkan penggunaan HTML untuk membuat struktur halaman web.
2. Menggunakan CSS untuk mengatur tampilan dan desain aplikasi.
3. Menggunakan JavaScript untuk mengolah input dan melakukan perhitungan matematika.
4. Membuat aplikasi kalkulator ilmiah yang interaktif dan mudah digunakan.

## Fitur Program
- Penjumlahan (+)
- Pengurangan (-)
- Perkalian (×)
- Pembagian (÷)
- Akar kuadrat (√)
- Perhitungan pangkat (x² dan xʸ)
- Sinus (sin)
- Cosinus (cos)
- Tangen (tan)
- Logaritma basis 10 (log)
- Logaritma natural (ln)
- Konstanta Pi (π) dan Euler (e)
- Tanda kurung untuk operasi matematika
- Tombol AC untuk menghapus semua input
- Tombol DEL untuk menghapus karakter terakhir
- Tombol Ans untuk menggunakan hasil perhitungan sebelumnya

## Teknologi yang Digunakan
1. **HTML**: Membuat struktur dan elemen kalkulator.
2. **CSS**: Mengatur warna, tata letak, ukuran tombol, dan desain tampilan.
3. **JavaScript**: Mengatur fungsi tombol dan proses perhitungan matematika.

## Cara Menjalankan Program
1. Unduh atau clone repository ini ke komputer.
2. Buka folder program menggunakan Visual Studio Code.
3. Pastikan file `index.html`, `style.css`, dan `script.js` berada dalam folder yang sama.
4. Buka file `index.html` menggunakan browser atau ekstensi Live Server di Visual Studio Code.
5. Gunakan tombol kalkulator untuk melakukan perhitungan.
